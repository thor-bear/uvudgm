# Avid Media Composer — Keyboard Shortcuts
## DCPR 1610 Quiz Review Sheet

> These are the shortcuts you are expected to know for the quiz. Learn the **function first**, the key second — understanding *what* each shortcut does is more important than memorizing letters.

---

## Marking & Navigation

*Before you can edit, you need to mark what you want and find your way around.*

| Key | Function |
|-----|----------|
| `I` or `E` | Set In mark |
| `O` or `R` | Set Out mark |
| `T` | Mark entire clip (sets In and Out at once) |
| `D` | Clear In mark |
| `F` | Clear Out mark |
| `G` | Clear both In and Out marks |
| `3` or `←` | Step back 1 frame |
| `4` or `→` | Step forward 1 frame |
| `1` | Step back 8 (or 10) frames |
| `2` | Step forward 8 (or 10) frames |
| `6` | Play In to Out |

---

## Core Editing

*The four foundational edits — know these cold.*

| Key | Function |
|-----|----------|
| `B` | **Overwrite** — drops source over existing material, no ripple |
| `V` | **Splice-In** — inserts source and pushes everything downstream |
| `X` | **Extract** — removes selection and closes the gap |
| `Z` | **Lift** — removes selection and leaves filler (black) |

---

## Segment Mode

*For moving and rearranging clips already in the Timeline.*

| Key | Function |
|-----|----------|
| `Shift + S` | Activate Extract/Splice-In Segment Mode tool (yellow) |
| `Shift + A` | Activate Overwrite/Lift Segment Mode tool (red) |
| `Shift + L` | Toggle Link Selection (keeps audio and video together) |

---

## Trim Mode

*Fine-tune edit points frame by frame.*

| Key | Function |
|-----|----------|
| `U` | Enter or exit Trim Mode |
| `Y` | Enter Source/Record mode (exits Trim Mode) |
| `Shift + D` | Select Overwrite Trim tool (red — sequence length stays fixed) |
| `Shift + F` | Select Ripple Trim tool (yellow — sequence length changes) |
| `A` | Go to previous edit point in Trim |
| `S` | Go to next edit point in Trim |
| `,` | Trim 1 frame to the left |
| `.` | Trim 1 frame to the right |
| `M` | Trim 8 (or 10) frames to the left |

---

## Effects & Markers

*Quick access to transitions, keyframes, and markers.*

| Key | Function |
|-----|----------|
| `/` | Open Quick Transition dialog |
| `'` (apostrophe) | Add keyframe |

---

## Tips for the Quiz

> [!tip] Red vs. Yellow — the key distinction
> **Red tools** (Overwrite, Lift, Overwrite Trim) affect *only* what you touch — the sequence length and surrounding clips stay put. **Yellow tools** (Splice-In, Extract, Ripple Trim) ripple outward — gaps open or close and the sequence length changes. If you remember nothing else, remember this.

> [!tip] Marks come in pairs
> In and Out always work together. `T` marks the whole clip at once. `G` clears both at once. `D` and `F` clear one at a time.

> [!tip] Trim Mode has its own navigation
> Once inside Trim Mode, `A` and `S` move between edit points — not the usual playhead keys. Think of it as its own mini-environment.
