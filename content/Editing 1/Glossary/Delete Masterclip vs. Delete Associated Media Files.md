# Delete Masterclip vs. Delete Associated Media Files

## Definition
Two different deletion options in Avid that look similar but do very different things. **Delete Masterclip** removes only the clip reference from the bin — the underlying media file on disk is untouched. **Delete Associated Media Files** (only available on imported clips, since linked clips have nothing of their own to delete) removes the actual media from the hard drive.

## Teaching Analogies & Examples
- **Removing a library card vs. burning the book**: Delete Masterclip just removes the card that says "this book is in our collection" — the book (the media file) is untouched. Delete Associated Media Files actually destroys the book itself.
- Worth saying plainly and slowly once: "one of these is undoable, the other is not" — that single sentence does more than any diagram to keep students cautious with this pair.
