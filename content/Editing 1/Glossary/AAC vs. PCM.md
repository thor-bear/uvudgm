# AAC vs. PCM

## Definition
Two audio codec options available when exporting. **AAC** is compressed and broadly compatible. **PCM** is uncompressed, but comes with a practical restriction relevant to this course: YouTube will reject a PCM file that has more than three mono audio tracks, so it only works reliably for delivery once those tracks are consolidated to stereo.

## In Practice
Explained in Lesson 7 as part of the Export to File walkthrough, with a direct instruction to set audio to **AAC** for the Montage export specifically because of PCM's mono-track limitation on YouTube. A concrete, practical rule rather than an abstract codec comparison — the choice is dictated by where the file is actually going.

## Teaching Analogies & Examples
- **A zipped file vs. the original folder**: AAC is compressed, like a zip file — smaller, more universally compatible, a little bit of quality traded for convenience. PCM is the raw, uncompressed original — bigger, but nothing lost, and pickier about how it's structured (hence the YouTube mono-track limit).
