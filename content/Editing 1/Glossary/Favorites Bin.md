# Favorites Bin

## Definition
A bin saved outside any single project so its contents (frequently reused assets — temp music, sound effects, graphics) are accessible from any project without re-importing them each time.

## In Practice
Demoed in Lesson 12: temp MP3s are placed in a bin in one project, saved to Favorites (highlight, right-click → add), then shown appearing automatically inside both the Gnarly and Rock Climber projects. Set up specifically as advance prep for Lesson 15's Stranger Things Assistant Editor interview, which references the Favorites Bin by name — a deliberate example of a lesson planting a reference that pays off two classes later.

## Teaching Analogies & Examples
- **A pantry shared by every recipe you cook**: instead of buying salt fresh for every single dish, it just sits in the pantry, available to any project without re-shopping for it each time.
