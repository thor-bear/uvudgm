# Favorites Bin

## Definition
A bin saved outside any single project so its contents (frequently reused assets — temp music, sound effects, graphics) are accessible from any project without re-importing them each time.

## Teaching Analogies & Examples
- **A pantry shared by every recipe you cook**: instead of buying salt fresh for every single dish, it just sits in the pantry, available to any project without re-shopping for it each time.
