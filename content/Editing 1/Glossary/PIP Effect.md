# PIP Effect

## Definition
Picture-in-Picture — an effect that displays one video layer inside a resized, repositioned frame over another, with parameters controlling size, position, border, and often drop shadow, all inside a single effect rather than stacked separately.

## Teaching Analogies & Examples
- **A TV showing a smaller TV inside it**: exactly like the classic news-broadcast picture-in-picture — a resized video window floating over the main video, with its own size, position, and border all adjustable inside one effect.
