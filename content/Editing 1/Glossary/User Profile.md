# User Profile

## Definition
Avid's container for an individual editor's personal customizations — keyboard mappings, interface settings, workspace layouts — kept separate from the shared application install so multiple students can use the same lab machine without stepping on each other's setups.

## In Practice
Created on Day 3, before any real editing happens (Lesson 3's Avid Setup section), so students have somewhere to land later customizations. Lesson 4 is built entirely around personalizing this profile via the **Command Palette**, and closes with the critical, easy-to-miss step: settings only save when the Settings window is open and **Cmd+S** is pressed — autosave does *not* capture them. At the end of Lesson 4 the profile gets exported (Standard setting, for portability); Lesson 5 proves the payoff by having students move to a new seat and re-import the exported profile there, demonstrating that their setup travels with them to any machine.

## Teaching Analogies & Examples
- **A gaming profile on a shared console**: multiple people use the same machine, but each person's saved settings, controls, and preferences stay separate and follow them to any console signed into their account.
- The "new seat, same profile" exercise in Lesson 5 is itself the best teaching tool — nothing explains portability like actually watching your own settings appear on a machine you've never touched before.
