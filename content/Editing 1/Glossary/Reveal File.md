# Reveal File

## Definition
A command that jumps from a clip inside Avid directly to that clip's actual file location on disk (in Finder/Explorer) — the fastest way to confirm where a piece of media physically lives.

## In Practice
Used in Lesson 5 right after linking and importing a small test file, specifically to make the Link-vs-Import distinction concrete rather than abstract: Reveal File shows a linked clip sitting in its original source folder untouched, while an imported clip shows up as new files inside the Avid MediaFiles folder. A quick, low-drama way to demystify "where did my footage actually go" for students early on.

## Teaching Analogies & Examples
- **"Show in Finder" on any file**: same idea as right-clicking a downloaded PDF and choosing "reveal in Finder" — it just jumps you straight to where the actual file lives on disk.
