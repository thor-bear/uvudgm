# Lined Script

## Definition
A copy of the shooting script marked up on set with vertical lines showing exactly which shots/setups cover which lines of dialogue and action — a visual map of coverage, tracked scene by scene as it's actually shot.

## In Practice
Introduced in Lesson 16 alongside the [[Script Supervisor]] role: the Lined Script is what that role produces and hands off to the editor, letting them understand what footage covers each scene *before* even watching the footage itself. Scene 9 is used as a worked example in class. The lesson notes a genuine gotcha worth flagging directly to students: Australian scene numbering conventions read differently than US ones, which can make an unfamiliar Lined Script confusing at first glance if that difference isn't explained up front.

## Teaching Analogies & Examples
- **A map with the route already highlighted**: instead of an editor reading a scene blind and rewatching every take to figure out what covers what, the Lined Script is handed over with the coverage already marked — like getting a map with the route drawn in instead of figuring out the roads yourself.
- The Australian-numbering gotcha is worth mentioning as a real-world example of why this document needs to be read carefully rather than skimmed — conventions genuinely differ project to project.
