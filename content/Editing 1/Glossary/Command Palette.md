# Command Palette

## Definition
Avid's central hub for every user-selectable button in the application, grouped by category (Move, Play, Edit, Trim, FX, etc.) — the tool used to build a custom interface and keyboard by dragging functions onto buttons or keys.

## In Practice
Shortcut: **Cmd+3**. Lesson 4 walks through the full customization checklist stored in this course's [[Avid Keybind Customizations]] doc using the Command Palette's **'Button to Button' Reassignment** mode (for keyboard/interface mapping) and **'Menu to Button' Reassignment** mode (for mapping a menu item, like Export to File, onto a key). While it's active, interface buttons stop responding to normal clicks — worth pre-warning students about, since "why is nothing clicking?" is a predictable early question.

## Teaching Analogies & Examples
- **A box of LEGO bricks for your keyboard**: every possible button/function exists in the Command Palette; customizing your interface is just dragging the pieces you actually use onto the keys and buttons you want them on.
- Warn students up front, as a memorable "why is nothing working" moment: while it's open, the app temporarily stops responding to normal clicks — it's not broken, it's just in "drag pieces onto the board" mode.
