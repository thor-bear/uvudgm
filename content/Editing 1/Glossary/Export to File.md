# Export to File

## Definition
Avid's dialog for rendering a finished sequence out to a deliverable video file — codec, resolution, audio format, and range settings are all configured here.

## In Practice
Menu shortcut in this course: **Shift+O** (File > Output > Export to File, per the [[Avid Keybind Customizations]]). Taught in Lesson 7 alongside a 1080p H.264 export setting for the Montage assignment, with two specific gotchas flagged: uncheck **"Convert to Full Range"** (otherwise a Rec.709 project exports larger than necessary), and pay attention to **[[Use Only Active Tracks]]**, since a common mistake is exporting without sound because the music track wasn't selected in the timeline's track selectors.

## Teaching Analogies & Examples
- **Printing a document, not just saving it**: your sequence is the working file (like an open Word doc); Export to File is hitting "Print" — it packages everything into a final, shareable, playable file that anyone can open, no Avid required.
