# Export to File

## Definition
Avid's dialog for rendering a finished sequence out to a deliverable video file — codec, resolution, audio format, and range settings are all configured here.

## Teaching Analogies & Examples
- **Printing a document, not just saving it**: your sequence is the working file (like an open Word doc); Export to File is hitting "Print" — it packages everything into a final, shareable, playable file that anyone can open, no Avid required.
