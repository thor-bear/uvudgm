# Bin

## Definition
A container file holding project assets — master clips, subclips, sequences, titles, effects — named after the physical bins that once held strips of celluloid film. In Avid, nothing can exist loose in a project; every asset lives inside some bin.

## In Practice
Lesson 3 has students set up their first project-level file structure (Class Projects / Class Media / Class Exports folders) alongside their first real bins. Lesson 6 has them build out a working bin set for the GNARLY project — **Interview, B-Roll, Music, Other, Sequences** — establishing the habit of organizing by content type from the start rather than dumping everything into one bin. Switchable between three layouts (Text, Frame, Script view); Frame view is what Lesson 9's Subclips workflow relies on for visually dragging selects into the Timeline.

## Teaching Analogies & Examples
- **A labeled folder in a filing cabinet**: nothing in Avid can just float loose — every clip, sequence, or title has to live inside some folder, the same way paperwork has to live in a labeled file, not just sit on the desk.
- The "why organize by content type from day one" pitch: ask students to imagine finding one specific interview clip in a project with 200 unsorted files versus one with Interview/B-Roll/Music bins already split out — the habit pays for itself the first time they're under deadline pressure.
