# Reset Grades

## Definition
Right-click a node tree → Reset Grades — returns a clip to an ungraded state, stripping node work while keeping the clip in place.

## In Practice
Used throughout this course to set up "visual matching, no node data" exercises: duplicate an already-graded set of clips, Reset Grades on the duplicates only, and match each reset clip to a reference (a JPEG still, or a scope reading) using only the eye and the scopes — no shortcut of importing someone else's node tree. Framed as the more transferable real-world skill, since a client handing over a reference screenshot with no node data is a common scenario.

## Teaching Analogies & Examples
- **Wiping a whiteboard clean before someone else uses it**: Reset Grades strips a clip's node tree back to nothing — a fresh, ungraded starting point — used deliberately in this course's Shot-Matching Part 2 exercise specifically to force students to match a reference by eye and scope, with no old node data left over to lean on as a shortcut.
