# AAF (Advanced Authoring Format)

## Definition
An editorial interchange format, primarily associated with Avid workflows — one of the export options (alongside XML and EDL) for handing a locked timeline to another application.

## In Practice
Once picture is locked using proxies, an editor exports an AAF (Avid) or XML (Premiere/Resolve) back to the colorist, who relinks it against the original full-resolution camera footage already imported in a Resolve project. Proxies never need to be imported into the coloring project at all, since timecodes/edit points map directly onto the full-res originals.

## Teaching Analogies & Examples
- **A moving truck's inventory list, not the furniture itself**: AAF describes an edit's structure (which clips, in what order, with what trims) so it can move between different software — like handing a new house's movers a detailed inventory instead of the furniture, so they know exactly what to set up where without you having to physically carry each piece yourself.
