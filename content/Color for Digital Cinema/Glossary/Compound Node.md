# Compound Node

## Definition
Multiple nodes collapsed into one for a tidier node tree.

## In Practice
Useful after a multi-node technique (like the Technicolor 3-strip PowerGrade conversion, which builds roughly 6 nodes) is dialed in and doesn't need further individual-node access — compounding it keeps the tree readable without losing the work. Not to be confused with a [[Atlas/Notes/Student Notes/Color for Digital Cinema/Glossary/Compound Clip]] (a timeline/editing-level nesting of multiple *clips*, not nodes).

## Teaching Analogies & Examples
- **Folding a messy group of files into one clean folder icon**: a Compound Node takes several individual nodes and collapses them into a single node in the tree — the work inside is unchanged, it's just tucked away behind one icon, keeping a complex tree from turning into visual spaghetti.
