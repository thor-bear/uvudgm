# Fairlight (Audio Page)

## Definition
Resolve's dedicated audio page — a full audio-post environment alongside the Media, Edit, Fusion, Color, and Deliver pages.

## In Practice
Used in this course for mastering 5.1 surround directly out of Resolve without a Premiere round-trip: import a conform XML, lay in all 8 audio tracks (Resolve auto-detects them as mono, no manual per-track setting required the way Premiere needs), then use **Link Group** to select tracks 1–6 and click "5.1" — a single action that auto-labels and correctly routes all six tracks based on layout order alone. This Resolve-native workflow is described in this course as simpler than the Premiere round-trip once you know it, though the Premiere-based version remains the more commonly taught path since most real-world handoffs still cross software.

## Teaching Analogies & Examples
- **A full recording studio built into the same building as the color suite**: Fairlight is Resolve's dedicated audio-mixing page — a proper mixing/mastering environment for dialogue, music, and sound design living right alongside the Color and Edit pages, so final audio work can happen without ever leaving the same application.
