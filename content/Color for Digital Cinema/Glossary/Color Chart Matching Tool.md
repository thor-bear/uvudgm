# Color Chart Matching Tool

## Definition
A small color-chart icon near the scopes — for shots where a physical color reference chart (X-Rite ColorChecker Classic or Legacy) was included in frame, Resolve can auto-align the chart's squares to a reference grid and auto-generate a match.

## In Practice
Described in this course with mixed results ("kind of works, kind of doesn't") and generally less trusted than manual grading, but worth knowing about. One genuine advantage over a technical LUT: it doesn't break [[Atlas/Notes/Student Notes/Color for Digital Cinema/Glossary/32-bit Float]] non-destructive grading — clipped results can still be recovered in a later node.

## Teaching Analogies & Examples
- **An answer key for a test, instead of grading by feel**: a physical color chart shot on set has known, documented correct values — the tool reads what the chart actually looks like in the footage and calculates exactly what correction would return it to that known-correct answer, taking the guesswork out of matching multiple cameras.
