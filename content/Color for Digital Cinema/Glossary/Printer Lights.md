# Printer Lights

## Definition
A numeric-keypad-mapped alternative to using the panel/wheels for global offset adjustments — named after old-school photochemical film-printing terminology. Requires a full keyboard with a numeric keypad; enabled with Option+Command+` (tilde).

## In Practice
Once active, each color/exposure axis maps to specific number keys (Exposure on +/Enter, Red on 7/4, Green on 8/5, Blue on 9/6, Cyan on 1/-, Magenta on 2/0, Yellow on 3/.). Framed in this course as a workflow some working colorists genuinely prefer for fast global/offset balancing, especially within a color-managed pipeline like ACES — presented as an option, not something students are expected to adopt.

## Teaching Analogies & Examples
- **A numeric keypad standing in for a mixing console**: instead of grabbing a wheel with the mouse, each number key nudges a specific channel (red, green, blue, exposure) up or down by a fixed amount — a fast, tactile, keyboard-only alternative some working colorists genuinely prefer for quick offset balancing, descended from literal photochemical film-printing controls of the same name.
- Worth framing as "an option, not homework" — this course explicitly presents it as bonus, not quiz material, and it's worth preserving that low-stakes framing when teaching it.
