# DRT (Diminished Resolve Timeline)

## Definition
A Resolve-native export a separate raw-media project can open and auto-relink to — the Resolve-specific alternative to exporting AAF/XML for a proxy-to-raw relink.

## In Practice
Mentioned in this course as a native alternative to the AAF/XML round-trip covered in more depth, specifically for all-Resolve workflows where the editing and coloring both happen inside Resolve rather than crossing into Premiere or Avid.

## Teaching Analogies & Examples
- **A stripped-down travel itinerary instead of the full trip journal**: a DRT carries just the essential edit structure — cuts, trims, basic ordering — without the extra detail a full project file would include, useful specifically as a lightweight interchange format when the receiving end doesn't need (or can't use) everything a native Resolve project contains.
