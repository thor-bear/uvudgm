# Locked Cut (Picture Lock)

## Definition
The finalized edit — no more changes to timing, order, or content — that everything downstream (conforming, color, VFX, sound) treats as the fixed reference to match against.

## In Practice
A reference video export of the locked cut is treated in this course as non-negotiable, not optional polish — it's the only way to verify a conform preserved the editor's exact cut, since colorists must never inadvertently alter the editor's timing. Verified via a D-key toggle at the first and last frame of every clip, comparing the reference against the conformed timeline.

## Teaching Analogies & Examples
- **The manuscript going to the printer**: once a book's text is locked, no more edits happen — layout, cover design, and everything downstream can now safely begin, because the words themselves won't move anymore. A Locked Cut is that same checkpoint for an edit: the picture is done changing, which is exactly what makes it safe to start conforming and grading against it without chasing a moving target.
