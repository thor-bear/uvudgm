# Versions (Grade Versioning)

## Definition
Resolve's non-destructive per-clip grade versioning system — Command+Y creates a fresh version of the grade on a clip, visible by double-clicking under a clip's timeline thumbnail. Command+B/Command+N step to the previous/next version. No apparent limit on how many versions a clip can have.

## In Practice
The standard technique behind nearly every before/after comparison in this course: create a new version, delete the non-primary nodes on it, and toggle between the two versions to judge a grade's effect. Also used to preserve independent grading attempts on the same shot (e.g. one version matching a director's own judgment, a second matching a provided reference exactly) without overwriting either.

## Teaching Analogies & Examples
- **Save-as, but built into the software**: instead of duplicating a whole project file to try a different grade direction, Versions let you keep multiple complete grades on the exact same clip, switchable with a click — like having "Draft 1," "Draft 2," and "Final" all open on the same page of a document.
- Good use case to state plainly: showing a director two competing looks on the same shot without ever leaving the clip or risking overwriting either one.
