# Show LUT (Pre-Production LUT)

## Definition
A custom LUT built by a colorist collaborating with the DP before production, using **only global primary corrections** (no qualifiers, windows, trackers, sharpening) — a hard technical requirement, since LUTs can only encode global transforms.

## In Practice
That show LUT can then be loaded into the camera for on-set monitoring, and a [[DIT (Digital Imaging Technician)|DIT]] can use the same underlying node structure for consistent dailies color throughout the shoot — closing loop framing for this course's case for pre-production colorist involvement. An IDT/ODT pair can serve the same on-set-monitoring purpose within a formal color-managed (ACES) pipeline — see [[IDT (Input Device Transform)]].

## Teaching Analogies & Examples
- **A rough sketch the DP and director agree on before the final painting begins**: a Show LUT gets built and agreed upon during pre-production as a rough visual target for the film's intended look — worn on set monitors so everyone can judge exposure/framing against something closer to the intended final image, even though the actual grade won't be finished until much later.
