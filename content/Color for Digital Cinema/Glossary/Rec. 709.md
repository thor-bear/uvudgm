# Rec. 709

## Definition
The television/broadcast color space — gamma 2.4 (aka BT.1886), SDR, narrowest gamut of the three spaces this course compares. Over 20 years old and showing its age against modern display capability, but still the default delivery target for most web content and this class's own deliverables.

## In Practice
This course's default (non-color-managed) project setting is DaVinci YRGB with Timeline/Output color space set to **Rec. 709 Gamma 2.4** — deliberately not the default "Rec.709-A" preset, which doesn't fit this workflow. Nearly every LUT, Color Space Transform, and ODT built in this course targets Rec. 709 as the output.

## Teaching Analogies & Examples
- **The "safe default" everyone can read**: Rec. 709 is the standard broadcast/HDTV color space — a smaller, older box of crayons compared to Rec. 2020, but one virtually every screen in the world can display correctly without any translation. It's the class default specifically because it's the color space students' work is most likely to actually be viewed correctly on, on whatever device grades their assignment.
