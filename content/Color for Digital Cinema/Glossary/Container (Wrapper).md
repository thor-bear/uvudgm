# Container (Wrapper)

## Definition
A file extension (.MOV, .MXF, .MP4, etc.) entirely separate from the codec inside it — analogized to a candy wrapper vs. the candy itself. The same codec can live in multiple container types (a ProRes file can be a .MOV or an .MXF), and the same extension can hold different codecs (a .MOV could be ProRes or H.264).

## In Practice
Practical implication: receiving a ".MOV file" from someone tells you almost nothing about its actual codec or quality — always check further, e.g. via [[Atlas/Notes/Student Notes/Color for Digital Cinema/Glossary/MediaInfo]] or Resolve's own metadata columns on the Media page. Common containers: .MOV, .MXF, .MP4, .MKV, .MPG — avoid .AVI and .WMV.

## Teaching Analogies & Examples
- **The box the vacuum-packed food ships in, not the food itself**: a Container (.mov, .mp4, .mxf) is the outer wrapper holding the actual compressed video and audio streams (the codec's job) plus metadata — the same codec can ship inside different container types, the way the same vacuum-sealed meal could be shipped in different boxes.
