# IMF (Interoperable Master Format)

## Definition
The modern, HDR/Dolby Vision/Dolby Atmos-capable successor to [[Atlas/Notes/Student Notes/Color for Digital Cinema/Glossary/DCP (Digital Cinema Package)]] — used by Netflix, Disney+, and high-end cinemas for delivery.

## In Practice
Named alongside DCP as one of the common deliverable types created from a finished master (ProRes downsamples, Blu-ray/DVD, H.264/HEVC web versions, DCP, IMF) — this course covers DCP creation hands-on but treats IMF as a name-check for where the industry is heading for HDR-capable, streaming-first delivery.

## Teaching Analogies & Examples
- **One master recipe, many regional menu versions**: IMF stores a film's picture/audio as reusable core components plus separate, swappable overlays for different versions (languages, regional edits, different subtitle sets) — rebuild just the pieces that differ per territory instead of exporting a whole separate full file for every single regional variant.
