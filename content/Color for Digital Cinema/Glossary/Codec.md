# Codec

## Definition
How footage was compressed into a file, and decompressed on playback — a format, not a piece of software. Three practical categories covered in this course: [[Visually Lossless (Intermediate Codec)]], raw (see [[Raw (Footage)]]), and [[High Compression (Deliverable) Codecs]].

## In Practice
Genuinely distinct from a [[Container (Wrapper)]] — a .MOV file tells you almost nothing about the codec inside it, since the same codec can live in multiple container types and the same extension can hold different codecs. Also distinct from an *encoder* — the same codec (e.g. H.264) produces genuinely different quality results depending on which software implements it. See [[Codec vs. Encoder]].

## Teaching Analogies & Examples
- **A specific method of vacuum-packing food**: a codec is the compression method used to shrink a video file down to a manageable size — different codecs are different vacuum-sealing techniques, some preserving more quality (and taking more space) than others, but all serving the same basic purpose of making the file smaller and more manageable to move around and play back.
