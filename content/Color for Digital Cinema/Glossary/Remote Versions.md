# Remote Versions

## Definition
A Resolve mechanism for automatically re-applying preliminary color when an XML gets re-imported at the final grading stage, so early on-set or dailies color choices aren't lost in the offline/online round-trip.

## In Practice
Mentioned in this course's DIT lesson but explicitly not demonstrated in depth ("too involved for this session") — flagged as a real, named feature worth knowing exists for preserving prelim color decisions through a full conform, even though this course's own labs handle that continuity manually.

## Teaching Analogies & Examples
- **Sending your grade to a coworker without emailing the whole file**: Remote Versions let a grade travel independently of the media itself — useful for collaborating across systems or facilities where the actual footage already lives on the other end, so only the (much smaller) grading data needs to move.
