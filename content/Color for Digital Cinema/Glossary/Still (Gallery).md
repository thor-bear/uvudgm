# Still (Gallery)

## Definition
A reference image (functionally a JPEG) grabbed from a shot — for visual comparison against a grade, with no node data attached. Distinct from a [[Atlas/Notes/Student Notes/Color for Digital Cinema/Glossary/PowerGrade]], which carries full node-tree information.

## In Practice
Both are created via the same "Grab Still" action — the distinction is which album it's saved into (Stills vs. PowerGrade), not a separate button. The **Stills gallery is project-specific**, unlike the PowerGrade gallery, which persists across every project on the same machine. Core to this course's shot-matching workflow: grab a Still of a satisfactorily-graded shot, then toggle it on/off as a live reference overlay (Cmd+W) while grading the next shot, checking both the visual match and the scope alignment between the two.

## Teaching Analogies & Examples
- **A photo pinned to the wall for reference, not the blueprint**: a Still is just an image to glance at and compare against — it has no data attached beyond what it looks like. Contrast directly with [[Atlas/Notes/Student Notes/Color for Digital Cinema/Glossary/PowerGrade]], which is the same idea but with the actual "how to build it" instructions attached.
- The "flip back and forth" workflow (Cmd+W) is worth demonstrating as a physical habit: grading while repeatedly toggling between "my shot" and "the reference" trains the eye far better than grading once and comparing at the end.
